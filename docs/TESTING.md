# Тестирование
## 1) Бэктест (оффлайн)
Данные: `data/devnet_prices_sample.csv` (пример).
Запуск:
```bash
python3 backtest_cli.py --csv data/devnet_prices_sample.csv --volume 250 --fee-ray-bps 25 --fee-orca-bps 20 --slippage-bps 10 --out-prefix out/backtest
```
**Что тестируется:** чувствительность к edge, влияние комиссий/порогов, сравнение маршрутов.
## 2) Интеграционный тест (Devnet/сухой прогон)
```bash
cd bot && npm test
```
**Что тестируется:** сбор маршрутов, корректность конфигов и доступ к RPC, генерация инструкций без отправки в сеть.
## 3) Shadow trading на Devnet
```bash
make bot-start
```
**Что тестируется:** непрерывный скан пулов, сборка транзакций, вызов демо‑инструкции `execute_swap` (без реального DEX‑CPI), метрики `/metrics`.
Для реальной торговли замените CPI внутри контракта на инструкции DEX.
## 4) Риски и мониторинг
Проверьте стопер CircuitBreaker и метрики на `http://localhost:9300/metrics`.


## 5) Profit Guard (атомарная защита прибыли)
Теперь транзакция включает:
- `minOut` на каждом шаге свопа (расчёт на клиенте исходя из fee+slippage).
- Финальную проверку `assert_profit`: контракт сверяет баланс целевого токен-аккаунта ДО/ПОСЛЕ маршрута и откатывает транзакцию, если профит меньше заданного порога.
